RISC-V emulator - Basic

RISC-V emulator

Able to run a limited version of risc-v instruction set.

Built in C, this project implements a RISC-V disassembler and emulator capable of decoding machine instructions and executing a subset of the RISC-V instruction set architecture.

  • • Decodes binary machine instructions into readable RISC-V assembly instructions.
  • • Emulates the execution of several dozen RISC-V instructions while updating registers and processor state.
  • • Provides optional execution tracing to display each instruction and its effect on register values.
  • • Supports register inspection for debugging, validating instruction behavior, and analyzing program execution.

Line follower Robot

Line Follower Robot

Self-navigated robot, using IR sensors.

Built with Arduino, this autonomous line-following robot uses five infrared sensors and PID control to track a dark line accurately, with optional Bluetooth control and real-time tuning through an Android interface.

  • • Uses five infrared sensors to detect the line position and calculate steering corrections.
  • • Supports proportional control or full PID control using adjustable Kp, Ki, and Kd values.
  • • Controls two continuous-rotation servos with differential speed adjustment for smooth and responsive steering.
  • • Includes stop-marker detection and lost-line handling for safer and more reliable navigation.
  • • Offers optional HC-06 Bluetooth communication for manual control and wireless configuration.
  • • Android controls allow real-time PID tuning and manual forward, backward, left, right, and stop commands.
